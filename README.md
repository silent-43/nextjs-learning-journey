# Next.js Learning Journey

A hands-on project documenting my journey of learning React and Next.js.

## Topics Covered

- React fundamentals, benefits, and limitations
- Installing Next.js and rendering HTML pages
- Next.js project structure and important files
- Creating pages and routes
- Navigation using Link and Router
- Dynamic routes in Next.js
- Developer Stories page
- Reusable StoryCard component
- Responsive layouts with Tailwind CSS

## Tech Stack

- Next.js
- React
- JavaScript
- Tailwind CSS
- Lucide React
- Git and GitHub

## Getting Started

Clone the repository:

```bash
git clone https://github.com/silent-43/nextjs-learning-journey.git
```

Go to the project directory:

```bash
cd nextjs-learning-journey
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser.
